# Официальные условия работы курьером и сборщиком в «Магнит»

Дата снятия данных: **2026-08-04**.
Метод: прямой WebFetch + браузерная навигация (get_page_text) по официальным доменам `magnit.ru` и его поддоменам. Домены-кандидаты из задания `magnit.ru/career` и `magnit.ru/job` — **проверены и не существуют** (HTTP 404 Not Found на оба URL, снято 2026-08-04). Реальный официальный портал вакансий — **rabota.magnit.ru** (SPA на том же домене, разные посадочные под конкретные роли/города); для курьеров отдельно действует **couriers.magnit.ru** (лендинг «Магнит Доставка» с тарифами, FAQ, калькулятором).

Легенда достоверности:
- **[OFFICIAL-CONFIRMED]** — факт снят напрямую с официального домена (`rabota.magnit.ru` или `couriers.magnit.ru`), текст получен либо через WebFetch, либо дословно через браузерный `get_page_text` (что надёжнее — рендерит JS-SPA полностью).
- **[UNVERIFIED]** — цифра встречается только на сторонних доменах-агрегаторах (rabotamagnit.online, courier-magnit.ru, magnitcurier.ru, rabota-magnit.ru, magnit-delivery.ru, rekrutix.ru и т.п. — НЕ поддомены magnit.ru) либо это WebFetch-суммаризация, которая при перепроверке браузером не подтвердилась. Требует ручной проверки Антонио.
- **нет публичной цифры** — ни на официальной странице, ни в доступных источниках цифра не встречена.

⚠️ **Важное расхождение, обнаруженное в процессе (для прозрачности методики)**: первый проход WebFetch по `couriers.magnit.ru/tarify-dla-samozanatyh-kurerov` выдал AI-суммаризацию с таблицей «тарифы для Москвы» (146/128/112/87 ₽ и т.д.). При прямой браузерной проверке той же страницы выяснилось, что она **не содержит выбора «Москва» по умолчанию** — дефолтный город рендерится как «Туймазы», а цифры из WebFetch-таблицы не совпадают ни с одним увиденным городом. Это похоже на галлюцинацию модели-суммаризатора WebFetch. Аналогично разошлось: WebFetch сообщил «средний доход 83 160 ₽/мес» для калькулятора, а прямой браузерный рендер показал **33 000 ₽/мес** при тех же вводных (6 ч/день, 22 дня/мес). **Ниже используются только цифры, подтверждённые дословным браузерным `get_page_text`, либо WebFetch-цитаты, которые содержат точную фразу в кавычках (не переработанные таблицы).**
